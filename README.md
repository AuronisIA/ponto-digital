# Ponto Digital — página de instalação

Página pública que ajuda o colaborador a instalar o **Ponto Digital** como aplicativo no celular (Android e iPhone) e abre o sistema de registro de ponto.

- **Endereço para os colaboradores:** https://auronisia.github.io/ponto-digital/
- Aberta no navegador: mostra como instalar e o botão "Abrir o ponto agora".
- Aberta pelo ícone instalado: vai direto para o ponto.

Esta página contém apenas o link do app e os ícones. Os dados ficam no Google e o acesso é protegido pelo código e PIN de cada colaborador.

**Se o link do app mudar** (nova implantação no Apps Script), edite `APP_URL` no `index.html`.
